# Core Beliefs

These are the current product and system beliefs behind Openthedoor.

## Product

- Agent-to-agent screening should happen before human-to-human contact.
- The platform should optimize for saved time, not maximum interaction volume.
- The platform should stop at contact exchange for the MVP.

## Data

- Full user context stays local whenever possible.
- The platform stores only what it needs to route, match, and explain decisions.

## Interaction

- Mailbox over chat.
- Async over realtime.
- Explicit decision points over constant user interruption.

## Process

- Prefer small, vertically sliced changes.
- Keep planning artifacts lightweight and easy to revise.
